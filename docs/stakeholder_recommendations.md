# Stakeholder Recommendation Framework

Use the following structure when presenting findings to a marketing or growth stakeholder.

| Finding type | What to communicate | Possible next step |
|---|---|---|
| ROAS decline | State the periods and the size of the change | Review campaign mix, audience, conversion rate, and attribution |
| Spend concentration | Show the largest account/campaign spend share | Review dependency and performance drivers |
| High ROAS at low spend | State both the ratio and absolute spend | Validate tracking, then run a controlled scale test |
| Revenue on zero-spend dates | Explain that ROAS is undefined for those dates | Check attribution lag, organic revenue, and spend ingestion |
| Budget pacing variance | State the budget definition and comparison period | Confirm budget scope and adjust pacing only after validation |
| Data mapping issue | Explain which comparisons may be affected | Resolve mapping before reallocating budget |

## Recommendation quality test

Before making a recommendation, ask:

1. Is the observation supported by a metric?
2. Is the metric calculated at the correct grain?
3. Have alternative explanations been considered?
4. Is the proposed action reversible and proportionate?
5. Is there a measurable follow-up criterion?

Use cautious language: “investigate,” “validate,” “test,” and “review” when evidence is incomplete. Use “increase” or “decrease budget” only when the supporting analysis is sufficient.
